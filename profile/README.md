# Bediga Labs

**AI tools built for Karimnagar first.**

Started on one laptop in Karimnagar, Telangana, India, by [Sharan Bediga](https://github.com/bsharan): Assistant Professor of
Computer Science and Engineering, AWS Certified Machine Learning Engineer – Associate.

We build small, honest tools for problems people here face every day: shops that sell without bills, public works
nobody can track, villages that run out of water in May. Each one is built in the open, tested, and measured.

## Products

| Product | What it does | Status |
|---|---|---|
| **Scam Check** | Suspicious call or message? Check it in Telugu in 30 seconds. Lost money? First-hour steps (1930) and a ready police complaint | [Live](https://bediga-labs.github.io/scam-check/) |
| **RTI Helper** | A citizen's letters in Telugu or English in 2 minutes: complaint → RTI application → first appeal; nothing leaves your phone | [Live](https://bediga-labs.github.io/rti-helper/) |
| **Tap-Counter** | One tap per sale for tea stalls and tiffin centres; a cash check every night | [Live phone app](https://bsharan.github.io/tap-counter/) |
| **Tally Counter, Resurrected** | Tap-Counter rebuilt with Kiro's spec-driven workflow (AWS Kiroween 2026) | [Live](https://bsharan.github.io/tally-counter-resurrected/) |
| **Tap-Counter Cloud** | Serverless night summary: Lambda, API Gateway, DynamoDB, EventBridge (AWS Weekend Challenge) | [Demo video](https://youtu.be/HOogRyRdMDc) |
| **Works Watch** | An AI agent that explains Karimnagar's public road and water works from official tender notices, with strict guardrails | Building (Nov–Dec 2026) |
| **Water Early Warning** | Forecasting which Karimnagar mandals will face groundwater stress before summer | Research (from Dec 2026) |

## How we work
Our own code and our own numbers. Bad results are reported too. Facts with sources, no opinions about people.
